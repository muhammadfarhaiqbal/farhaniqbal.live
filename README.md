## 🎨 How to Add Your AI-Generated Avatar Photo

When you generate an avatar portrait (using ChatGPT / Midjourney / Flux / Leonardo with the prompt provided below), simply:
1. Save your image as **`avatar.png`** (or `avatar.jpg`) inside the `assets/` folder:  
   `c:\Users\hp-laptop1\Downloads\FARHAN PORTFOILIO\assets\avatar.png`
2. In [`index.html`](file:///c:/Users/hp-laptop1/Downloads/FARHAN%20PORTFOILIO/index.html#L145), inside `<div class="avatar-display" id="avatarDisplay">`, you can add:
   ```html
   <img src="assets/avatar.png" alt="Farhan Iqbal" class="avatar-img" />
   ```
   The site already includes the styling to automatically display it with futuristic holographic scanlines and glowing neon borders!
